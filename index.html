Performance

Tuned before the game even starts.

Most launchers hand Minecraft to Java with default flags and hope for the best. Volex picks a garbage collector, sizes the heap to your machine, caches class data between launches, and gets out of the way once you are playing.

Garbage collection
G1 or generational ZGC, chosen for the version you run. Fewer pauses, so fewer sudden frame drops.
Startup
AppCDS caches the JVM's class data, so the game reaches the title screen sooner and holds less memory doing it.
Memory
The heap is sized to your installed RAM. No hand-edited launch flags, no swapping to disk mid-game.
Compilation
JIT flags that let the compiler handle Minecraft's oversized methods instead of skipping them.
Priority
Once the game is running, Volex lowers its own CPU priority and hands the cores to Minecraft.
Features

Everything the launcher should do, and nothing it shouldn't.

Profiles

Every install is independent, with its own version, loader, memory and mods. Group them, reorder them, switch in a click. One profile can never break another.

Renderer selection

Pick the Sodium suite for broad compatibility, or move rendering to Vulkan with VulkanMod. Volex knows which mods conflict and won't let you build a broken combination.

Java management

Volex detects the JDKs already on your PC and downloads the exact version a release needs from Adoptium when it's missing. You never install or point at Java yourself.

Mod management

Search Modrinth, then install, update and disable mods without leaving the launcher. Volex fingerprints each jar with SHA-1 to find genuine updates, and imports .mrpack modpacks directly.

Shaders

Add Iris from the mod browser and it slots in with the rest of your mods. Volex opens the instance folder so your shader packs land in the right place.

Performance tuning

G1 or ZGC, AppCDS class sharing, JIT flags and a right-sized heap, applied automatically per profile. The same tuning ships with the app, with no config files to edit.

Security

Downloads are checked against Mojang's SHA-1 hashes. Modpack archives extract inside their instance and nowhere else. Friend presence is verified with Mojang, so nobody can impersonate you.

Downloads

Assets and libraries download in parallel in the background, verified as they arrive. A failed file retries on its own instead of leaving you with a broken install.

Crash Doctor

When a launch fails, Volex reads the crash report and tells you the likely cause in plain language, from missing dependencies to the wrong Java version.

FAQ

Questions, answered plainly.

Is Volex free?
Yes. Volex is free to download and use on Windows. You still need your own Minecraft account to play online.
Do I need Java installed first?
No. Volex checks for a suitable JDK on your PC and, if it doesn't find one, downloads the exact version a release needs from Adoptium. You never manage Java by hand.
Which versions and mod loaders does it support?
Release and snapshot versions, on Fabric, Forge, NeoForge and Quilt. Each profile keeps its own loader and version, so you can run several side by side.
Will it actually make my game faster?
It makes startup quick and keeps frametimes steadier through JVM tuning, with no mods involved. For a large jump in frame rate, install the Sodium suite in one click. How much you gain depends on your hardware, so we won't quote a number we can't guarantee.
Is my account safe?
Your sign-in is handled through Microsoft's official flow and your tokens stay on your machine. Friend presence is checked against Mojang's servers, so no one can appear as you.
Is there a Mac or Linux build?
Not yet. Volex is Windows-only for now. That focus is what lets the Java handling and installer stay this hands-off.
